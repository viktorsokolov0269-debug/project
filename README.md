# Сопоставление ОЭ и ОР (1С ERP × 1С ТОИР)

Веб-приложение для удобного сопоставления объектов эксплуатации (ОЭ) из 1С ERP с объектами ремонта (ОР) из 1С ТОИР.

## Возможности

- Загрузка двух Excel-таблиц: **ОЭ** (~800) и **ОР** (~2000) — столбцы «Код» и «Наименование»
- ОЭ — основа списка; для каждой строки выбор ОР через выпадающий список с поиском
- Фильтры: все / без пары / сопоставленные
- Проверка дубликатов: один ОР нельзя спокойно повесить на несколько ОЭ (подсветка и список проблем)
- Экспорт результата в **Excel** и **JSON** (4 столбца: код/наименование ОЭ + код/наименование ОР)
- Прогресс сохраняется в `localStorage` браузера

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Формат входных файлов

Первый лист Excel. Заголовки распознаются гибко (`Код`, `Наименование`, `Code`, `Name` и т.п.). Если заголовков нет — берутся первые два столбца.
